# 架构（脚本阶段）

- `adb.py`：ADB 发现、设备选择、基础设备信息、前台包检测、Hierarchy 和截图采集。
- `ui.py`：解析 UIAutomator XML；选择器必须精确匹配，点击坐标来自唯一节点或其最近可点击祖先。
- `safety.py`：检测疑似人工验证及风险操作词。
- `tasks.py`：受限 JSON 状态流程；最多 20 步，等待上限 120 秒，重试上限 2 次；每次点击要求验证结果。
- `cli.py`：命令行入口。

现阶段不含截图 OCR、模型调用、循环挂机、游戏私有数据访问或自动登录。游戏页面目前尚未实机观察，任务流程是待设备校准的配置，而不是已支持的游戏任务。
