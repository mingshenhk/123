# 路线

## 脚本 V0.1（本阶段）

- ADB 设备、游戏前台和基础设备信息检查。
- Screenshot 与 UIAutomator hierarchy 采集。
- 精确文本选择、单步点击和结果等待。
- JSON 有界规则任务、停止机制和验证/风险拦截。

## 下一步

1. 连接雷电模拟器或手机，确认 ADB 可见和游戏已由用户登录。
2. 检查游戏界面是否提供可访问节点；先只读观察。
3. 选一个安全、可逆的实际按钮做单次测试，记录前后状态。
4. 根据真实界面编写并验证第一个任务配置。
5. 之后再决定 Android APK 与本地 AI 的集成形式。

没有设备运行时验证前，不宣称支持挂机、自动战斗或任何完整任务。
